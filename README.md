# REMBYTTECH — стартовый проект сайта

Премиальный сайт сервисного центра «РемБытТех» (Лазаревское, Сочи).

## Структура
- `client/` — React + Vite: сайт, каталог, формы, интерфейс чата и админ-панель.
- `server/` — Node.js + Express + SQLite: заявки, товары, сообщения, Telegram и Email-уведомления.

## Запуск локально
Нужны Node.js 20+ и npm.

### 1. Сервер
```bash
cd server
cp .env.example .env
npm install
npm run dev
```

### 2. Клиент (во втором терминале)
```bash
cd client
npm install
npm run dev
```
Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Важно перед публикацией
Это рабочая стартовая версия, а не уже подключённый production-сервис.
1. Заполнить `server/.env`: Telegram bot token/chat ID, SMTP, секрет администратора.
2. Настроить HTTPS, домен, резервное копирование и постоянный сервер.
3. Заменить демонстрационные товары реальными фотографиями, ценами и остатками.
4. Добавить согласие на обработку персональных данных и опубликовать политику конфиденциальности.
5. Перед открытием админки усилить авторизацию (например, полноценные аккаунты сотрудников, ограничение попыток входа, смена паролей, аудит действий).
6. Проверить требования законодательства РФ к обработке и хранению персональных данных. Не хранить лишние данные.

## Админ-панель
В интерфейсе нажмите «Для сотрудников» внизу сайта. Для входа используйте пароль из `ADMIN_PASSWORD` в `.env`.
По умолчанию пароль намеренно не задан: настройте его до запуска.
Для публичного демо без настроенного сервера формы не будут отправляться — сначала запустите backend.
